## Features

<table>
<tr><td>

- **Combat** — AutoCrystal, Surround, Burrow, Offhand, AutoPot
- **Movement** — Flight, Speed, AntiVoid, Clip
- **Visual** — ESP, Chams, Nametags, XRay, Trajectories, FreeCam
- **Misc** — Disabler, PingSpoof, AutoTool, NoRender, Timer
- **Legit** — AimAssist, TriggerBot, Clicker, JumpReset

</td><td>

- **ClickGUI** — Press `Right Shift`
- **HUD Editor** — Fully customizable overlay
- **Config System** — Local & cloud configs with icons
- **Addon API** — Extend via [`ADDON_DEV_GUIDE.md`](ADDON_DEV_GUIDE.md)
- **Baritone & Sodium** — First-class compatibility

</td></tr>
</table>

## Build

```bash
git clone https://github.com/LimonTH/Blackout-CE
cd Blackout-CE
./gradlew build
```

> Requires **JDK 21**. Output: `build/libs/blackout-*.jar`
